원드라이브로 휴대폰과 패드 연결

한 번 앱을 등록한 뒤, 두 기기에서 같은 계정으로 로그인합니다. 비밀 키나 Microsoft 비밀번호를 운명공부에 입력하지 않습니다.

1. 최초 앱 등록 — 한 번만

  1. Microsoft Entra 관리 센터에서 앱 등록 → 새 등록을 엽니다. 앱을 등록할 수 있는 디렉터리/권한이 필요하며, 회사 계정에서는 관리자 도움이 필요할 수 있습니다.
  2. 이름은 운명공부, 지원 계정은 모든 조직 디렉터리의 계정 및 개인 Microsoft 계정을 선택합니다.
  3. 리디렉션 플랫폼은 SPA(단일 페이지 애플리케이션), 주소는 아래와 정확히 같게 등록합니다.
    https://msjung75.github.io/unmyeong/onedrive-return.html
  4. API 사용 권한 → Microsoft Graph → 위임된 권한에 Files.ReadWrite.AppFolder를 추가합니다. 이 앱의 전용 폴더에만 접근합니다. 클라이언트 비밀 키는 만들지 않습니다.
  5. 개요의 애플리케이션(클라이언트) ID를 복사합니다. 이 ID는 비밀 키가 아닙니다.

2. 휴대폰과 패드에서 각각 연결

  1. 운명공부 설정 → 원드라이브에서 위의 동일한 앱 ID를 입력하고 Microsoft 로그인을 누릅니다.
  2. 두 기기에서 같은 OneDrive 계정을 선택합니다. 로그인과 접근 동의는 Microsoft 화면에서 진행합니다.
  3. 앱으로 돌아오면 같은 동기화 암호(8자 이상)를 정해 두 기기에 입력하고 동기화 시작을 누릅니다. 이미 연결한 기기가 있으면 그 기기와 같은 암호를 사용합니다.

암호화된 기록은 OneDrive의 Apps/운명공부 전용 폴더에 저장됩니다. ‘이 기기에서 기억하기’를 선택하면 해당 브라우저에 연결 정보를 보관하고 다음부터 자동 연결합니다. 공용 기기에서는 선택하지 마세요. 설정에서 연결 해제 시 저장된 암호를 삭제합니다. 암호를 잊으면 해당 암호화 파일을 복구할 수 없습니다. 기존 기기 기록과 JSON 백업은 별개로 유지됩니다.

3. 일상적으로 쓰는 방법

입력은 먼저 기기에 저장하고, 잠시 멈추면 전송합니다. 화면이 열려 있는 다른 기기는 약 8초마다 변경을 확인합니다. 인터넷·OneDrive 응답에 따라 더 걸릴 수 있으며 화면을 닫은 상태에서는 동기화하지 않습니다.

다른 기기의 기록이 도착해도 입력 중인 칸을 덮지 않습니다. 편집을 마치면 반영합니다. 같은 명식을 동시에 수정했다면 설정 → 동시 수정 기록 확인에서 보고, 선택하지 않은 내용도 사본으로 남길 수 있습니다.

명식·일반 메모·연도 메모·강의 노트·저장 GPT 풀이가 대상입니다. 녹음 원본과 녹음별 받아쓴 내용, 화면 설정은 각 기기에 남습니다. 기존 백업 파일은 자동 가져오기하지 않습니다. 필요한 백업은 연결 전에 앱에서 가져오세요.
