# 운명공부

만세력과 명식 기록을 위한 브라우저 앱입니다.

- 서비스: https://msjung75.github.io/unmyeong/
- `index.html`을 GitHub Pages로 배포하며 별도 빌드가 필요하지 않습니다.
- 사용자 기록은 사용하는 브라우저에 보관됩니다. 설정에서 JSON 파일로 별도 백업할 수 있습니다.

## v1.62 전문가 화면 색상·사람 찾기

- 전문가 명식의 천간·지지와 대운·세운·월운을 기존 오행 색상 카드로 통일했습니다.
- 오른쪽 위의 현재 이름을 누르면 이름·태그·생년월일로 사람을 검색하고 바로 전환할 수 있습니다.

## v1.61 전문가 화면

- 상단 **일반 / 전문가** 또는 설정에서 화면을 바꿀 수 있으며 선택은 이 브라우저에 기억됩니다.
- 바로 열기: https://msjung75.github.io/unmyeong/?mode=expert
- 전문가 화면은 색상 타일과 반복 안내 대신 명식표에 천간·지지·십성·지장간·12운성을 정렬합니다. 원국과 운을 구분하고 일주를 강조합니다.
- 대운·세운·월운을 작은 글자 중심으로 표시하며 기존 연도 선택, 월운 상세, 현재 운, 비교, 메모, 공유, PDF 기능에 연결됩니다.
- 합충형파해와 상담 기록은 펼쳐서 보고, 기본 풀이와 저장된 AI 풀이는 별도 창에서 확인합니다.
- 화면 전환은 표시 설정만 변경합니다. 기존 인물·메모·녹음 저장 키 및 계산 엔진은 그대로 사용합니다.
- 폴더폰·태블릿에서는 너비를 활용하고 1100px 이상에서 명식과 운을 나란히 배치합니다.

## v1.58 변경 사항

- 입춘 기준 연주 연도와 실제 양력 출생연도를 분리해 나이·대운 연도 표시를 일치시켰습니다.
- 원국과 선택한 운을 구분하고, 한글 독음과 간단히/자세히 보기를 추가했습니다.
- 시간 보정 전후와 날짜 전환·대운 계산 기준을 확인할 수 있습니다.
- 월운을 누르면 내장 절기표의 KST 적용 기간과 원국과의 관계가 표시됩니다.
- PC 화면은 두 열로 배치하고 작은 화면의 글자·버튼·가로 스크롤을 개선했습니다.
- **명식 → 더보기 → PDF**에서 포함 항목을 선택한 뒤 브라우저의 **PDF로 저장**을 이용할 수 있습니다. 풀이·메모는 기본 제외되며 기본 개인정보 가리기를 선택할 수 있습니다.
- 백업 안내를 바로잡고 공유 취소·내보내기 준비 실패를 백업 성공으로 기록하지 않도록 했습니다.
- AI에 원국·대운을 구분해 전달하고 생성 당시 계산 조건을 기록합니다. 이전 풀이도 유지됩니다.

저장 키와 기존 인물·메모·녹음 형식은 유지합니다. −30분 보정은 고정 보정이며 지역별 진태양시를 계산하지 않습니다. 대운은 기존 반올림 대운수 규칙을 사용합니다.

## 검증

Node.js 18 이상에서 실행합니다.

```sh
npm ci
npm test
```

검증 항목: 연초 생일의 나이와 대운 전환, 음력·시간 미상, 시간 보정, 12개월 절기 경계, 화면 조작, PDF 개인정보 옵션, 공유 링크 확인 절차, 백업 취소·실패.

자동 검증은 jsdom에서 수행하며 실제 기기의 인쇄·파일 공유 UI는 브라우저에 따라 다릅니다.

## v1.59 반응형 화면

- 600px 이상인 펼친 폴더폰과 태블릿에서는 앱 폭을 넓히고 현재·공유·비교·PDF·수정·삭제 메뉴를 항상 표시합니다.
- 넓어진 화면에서는 대운·세운·월운의 더 많은 항목을 한 화면에 표시합니다.
- 900px 이상에서는 명식과 운세를 두 열로 배치하고, 1280px 이상에서는 운세 영역을 더 넓게 사용합니다.
- 휴대폰의 기존 배치와 사용자가 고른 `간단히/자세히` 설정은 유지합니다.

## v1.60 화면 정렬 수정

- 펼친 폴더폰과 태블릿에서 원국 구분선의 여백 때문에 시주만 작게 보이던 문제를 수정했습니다.
- 구분선은 칸 바깥에 표시해 시주·일주·월주·연주가 모두 같은 크기로 보입니다.
