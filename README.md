# 운명공부

만세력과 명식 기록을 위한 브라우저 앱입니다.

- 서비스: https://msjung75.github.io/unmyeong/
- `index.html`을 GitHub Pages로 배포하며 별도 빌드가 필요하지 않습니다.
- 사용자 기록은 사용하는 브라우저에 보관됩니다. 설정에서 JSON 파일로 별도 백업할 수 있습니다.

## v1.65 원드라이브 기기 간 공유

- 설정에 Microsoft 로그인과 동기화 연결을 추가했습니다. **배포 기본값은 앱 ID가 비어 있어 실제 연결은 아직 활성화되지 않습니다.** [최초 앱 등록 안내](onedrive-setup.html)를 따라 Microsoft Entra 앱을 한 번 등록하고 두 기기에 같은 공개 클라이언트 ID를 입력합니다. 클라이언트 비밀 키는 사용하지 않습니다.
- 같은 Microsoft 계정과 같은 동기화 암호로 연결하면 명식, 일반·연도·강의 메모, 저장된 GPT 풀이를 공유합니다. 녹음 원본과 녹음별 받아쓰기(`recs`)는 각 기기에 남습니다.
- 화면이 열려 있을 때 약 8초마다 확인합니다. 오프라인 변경은 기기에 저장하고 재연결 시 전송합니다. 다른 기기의 변경은 입력을 마친 뒤 반영합니다. 백그라운드 즉시 전송은 보장하지 않습니다.
- 전용 앱 폴더에 기기별 암호화 파일을 저장합니다. ‘이 기기에서 기억하기’를 선택하면 IndexedDB에 비추출 AES 키와 암호화한 동기화 암호를 저장하고 다음부터 자동 연결합니다. 키도 같은 브라우저에 있으므로 기기 잠금을 대신하지 않습니다. Microsoft 로그인 캐시는 localStorage에 유지하며 만료 시 재로그인이 필요할 수 있습니다. 연결 해제는 저장된 암호와 이 앱의 인증 캐시를 지우며 명식·메모는 유지합니다. 같은 명식을 동시에 수정하면 양쪽 내용을 보존하고 사용자가 확인하여 다른 수정본도 사본으로 남깁니다.
- 기존 백업 파일을 변경하지 않습니다. 연결 후에는 예전 파일 연결 자동 저장·자동 불러오기를 중지하여 오래된 파일로 덮어쓰는 일을 막습니다.
- 자동 테스트는 두 기기를 가정한 모의 Graph 전송으로 암호화, 오프라인 복귀, 충돌 보존, 잘못된 암호 차단, 입력 중 반영 유예를 검증합니다. 실제 Microsoft 계정 두 기기 검증은 앱 등록 후 진행해야 합니다.

## v1.64 명식 옆 메모장

- 휴대폰은 명식 아래 **명식 보며 메모**를 누르면 바로 작성합니다. 화면 폭 660px 이상인 펼친 폴드·태블릿에서는 명식 왼쪽 / 메모 오른쪽으로 자동 배치합니다. 메모장을 접으면 명식이 전체 너비로 돌아옵니다.
- **연도 메모**: 올해·내년·직접 입력으로 세운과 메모를 함께 바꿉니다. 기존 같은 해의 여러 기록은 선택해서 이어 쓰고, 새 메모도 추가할 수 있습니다. 대운 표시 범위 밖에서도 지정 연도 세운을 표시합니다.
- **강의 메모**: 사람별로 제목을 붙인 수업 노트를 여러 개 작성합니다. **일반 메모**는 기존 인물 메모를 그대로 사용합니다. 글자는 16~26px로 조절하고 녹음 도구도 메모장 아래에서 펼칩니다.
- 입력 즉시 해당 사람·연도 기록에 반영하고 450ms 뒤 자동 저장합니다. 연도/사람을 빠르게 바꿔도 기록이 섞이지 않으며, 저장 실패 시 편집 내용과 실패 상태를 유지합니다. 저장 작업은 직렬 처리합니다.
- 아래 **메모** 메뉴는 연도 기록·강의 메모·일반 메모·녹음을 모아 보는 곳입니다. 강의 노트는 기존 JSON 백업에 포함됩니다. 기본 저장은 기기별이며 설정의 백업 내보내기/가져오기로 옮길 수 있습니다. v1.65부터 별도 연결 시 원드라이브 공유를 지원합니다.

## v1.63 단일 명식 화면 · 메모 · GPT 연결

- **GPT 풀이 → ChatGPT에서 풀이**: 별도 API 설정 없이 현재 명식을 복사하고 ChatGPT를 엽니다. 사용자가 직접 붙여넣고 보내는 방식이며, 현재 ChatGPT 대화나 앱으로 답변이 자동 전달되지는 않습니다. 복사/새 창이 차단되면 명식 선택과 열기 링크를 제공합니다. 생년월일을 URL에 넣지 않습니다.
- **받은 풀이 붙여넣어 저장**: ChatGPT 답변을 사람별·연도별로 저장합니다. 다음에 같은 사람/연도를 열면 이 내용을 사용하며 다시 생성하지 않습니다. 수정과 JSON 백업을 지원합니다. 보낸 명식의 계산 조건을 기록하고 조건이 달라지면 표시합니다. ChatGPT 답변 수신은 자동화하지 않으며 사용자가 복사·붙여넣습니다.

- 일반/전문가를 하나로 통일했습니다. 첫 화면은 원국과 대운을 보여 주고, 대운 → 세운을 누르면 아래에 세운 → 월운이 펼쳐집니다. 이름을 누르면 운 표시가 접힙니다. 검색은 목록에서 사용합니다.
- 선택 전에도 세운·대운 자리를 비워 두어 원국 타일 크기가 바뀌지 않습니다. 타일·여백·글자를 조정했습니다.
- 기존 규칙 기반 총평과 연도 풀이를 화면과 PDF에서 제거했습니다. 이전 저장 AI 결과와 모든 메모·녹음 원본은 유지됩니다.
- 메모는 일반 메모 → 음성 기록 → 접힌 연도별 기록 순서입니다. 녹음은 원본 저장 후 파일별 글 변환·수정·메모 추가로 분리했습니다. 실시간 음성인식 자동 재시작을 제거했습니다.
- GPT 풀이/음성 글 변환의 연결 코드가 포함되어 있습니다. **실제 사용은 서버 배포와 OpenAI API 설정 후 가능**합니다. [서버 연결 안내](server/README.md)를 참고하세요. 키는 브라우저에 보관하지 않습니다.

- 대운·세운·월운을 작은 글자 중심으로 표시하며 기존 연도 선택, 월운 상세, 현재 운, 비교, 메모, 공유, PDF 기능에 연결됩니다.
- 합충형파해와 상담 기록은 펼쳐서 보고, 기본 풀이와 저장된 AI 풀이는 별도 창에서 확인합니다.
- 화면 전환은 표시 설정만 변경합니다. 기존 인물·메모·녹음 저장 키 및 계산 엔진은 그대로 사용합니다.
- 폴더폰·태블릿에서는 너비를 활용하고 1100px 이상에서 명식과 운을 나란히 배치합니다.

## v1.58 변경 사항

- 입춘 기준 연주 연도와 실제 양력 출생연도를 분리해 나이·대운 연도 표시를 일치시켰습니다.
- 원국과 선택한 운을 구분하고, 한글 독음과 간단히/자세히 보기를 추가했습니다.
- 시간 보정 전후와 날짜 전환·대운 계산 기준을 확인할 수 있습니다.
- 월운을 누르면 내장 절기표의 KST 적용 기간과 원국과의 관계가 표시됩니다.
- PC 화면은 두 열로 배치하고 작은 화면의 글자·버튼·가로 스크롤을 개선했습니다.
- **명식 → 더보기 → PDF**에서 포함 항목을 선택한 뒤 브라우저의 **PDF로 저장**을 이용할 수 있습니다. 풀이·메모는 기본 제외되며 기본 개인정보 가리기를 선택할 수 있습니다.
- 백업 안내를 바로잡고 공유 취소·내보내기 준비 실패를 백업 성공으로 기록하지 않도록 했습니다.
- AI에 원국·대운을 구분해 전달하고 생성 당시 계산 조건을 기록합니다. 이전 풀이도 유지됩니다.

저장 키와 기존 인물·메모·녹음 형식은 유지합니다. −30분 보정은 고정 보정이며 지역별 진태양시를 계산하지 않습니다. 대운은 기존 반올림 대운수 규칙을 사용합니다.

## 검증

Node.js 18 이상에서 실행합니다.

```sh
npm ci
npm test
```

검증 항목: 연초 생일의 나이와 대운 전환, 음력·시간 미상, 시간 보정, 12개월 절기 경계, 화면 조작, PDF 개인정보 옵션, 공유 링크 확인 절차, 백업 취소·실패.

자동 검증은 jsdom에서 수행하며 실제 기기의 인쇄·파일 공유 UI는 브라우저에 따라 다릅니다.
